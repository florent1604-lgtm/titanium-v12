# Reporting à la demande

Le reporting périodique est désactivé. Le suivi est produit uniquement lorsque Florent écrit :

```text
/repoting
```

> L’orthographe `repoting` est volontairement conservée pour correspondre à la commande demandée. L’alias humain `reporting` peut être interprété de la même façon lorsqu’il est envoyé en texte.

## Contenu obligatoire

1. Tableau Hermes / Claude / Codex / JARVIS / Titanium.
2. Dernière avancée prouvée, statut et blocage/validation suivante.
3. Changements vérifiables depuis le dernier rapport manuel.
4. Rappel : **PAPER ONLY — aucun ordre réel autorisé.**

## Contraintes

- Lecture seule : aucun redémarrage, modification ou ordre déclenché par le reporting.
- Les preuves viennent de `TASKS.md`, `LOG.md`, `REVIEWS.md`, bus append-only, Git et états/ports si disponibles.
- En l’absence de preuve nouvelle : écrire explicitement `Aucun changement prouvé`.
